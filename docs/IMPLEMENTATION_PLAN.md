# 实现计划

本文档把 MVP 拆成可开发任务，便于 Codex 或开发团队逐步实现。

## 1. 开发原则

- 先完成学生诊断闭环，再做老师端和 AI 自动化。
- 先使用人工录入或内置真题式题库，再接入整卷 AI 拆题。
- 所有正式题目必须保留审核状态和发布状态。
- 新功能必须满足 `ACCEPTANCE_CRITERIA.md` 中相关验收项。
- 每个阶段完成后都要补充必要测试。

## 2. 第一阶段：正式项目骨架

目标：从静态原型升级为可扩展工程。

任务：

- 选择正式技术栈。
- 建立前端项目结构。
- 建立后端项目结构。
- 建立数据库迁移机制。
- 建立用户认证基础。
- 建立代码格式化和测试脚本。
- 建立环境变量管理。

验收：

- 项目可以本地启动。
- 前端、后端、数据库连接正常。
- 基础测试命令可运行。
- 敏感配置不进入前端代码。

## 3. 第二阶段：学生账号和权限

任务：

- 实现学生注册。
- 实现学生登录。
- 实现退出登录。
- 实现密码哈希存储。
- 实现基础 RBAC。
- 实现学生只能访问自己的学习记录。

验收：

- 不同学生数据隔离。
- 密码不明文存储。
- 未登录用户不能访问学习数据。

## 4. 第三阶段：知识图谱和题库基础

任务：

- 建立 KnowledgePoint 数据表。
- 建立 KnowledgeRelation 数据表。
- 建立 Question 数据表。
- 建立题目审核状态和发布状态。
- 建立题目知识点挂接表。
- 导入一批 MVP 示例题。
- 实现学生端获取已发布题目。

验收：

- 学生端只能看到已发布题目。
- 知识点支持 parent 和 prerequisite。
- 每道题至少有主知识点。

## 5. 第四阶段：学生做题诊断

任务：

- 实现获取下一题。
- 实现题目开始作答记录。
- 实现提交答案。
- 实现用时统计。
- 实现正确性判断。
- 实现学生难度反馈。
- 实现时间评估。

验收：

- 每次作答都有 startedAt、submittedAt、durationSeconds。
- 学生难度反馈保存。
- 过快答错不在学生端显示负面标签。

## 6. 第五阶段：错后学习导航

任务：

- 实现错因提示生成。
- 实现前置知识点推荐。
- 实现补救路径创建。
- 实现前置知识点补救题。
- 实现补救完成后回到原知识点复测。

验收：

- 答错后能看到错因、前置知识、路径、提示和鼓励语。
- 完成补救后能回到原知识点。
- 补救记录可查询。

## 7. 第六阶段：奖励和学习伙伴

任务：

- 实现 XP、宝石、生命值、连续学习。
- 实现奖励事件表。
- 实现成长型奖励规则。
- 实现徽章。
- 实现学习伙伴头像状态。

验收：

- 补清前置知识奖励高于答对普通基础题。
- 认真复盘有奖励。
- 答错动画温和，不责备学生。

## 8. 第七阶段：学习报告

任务：

- 实现学生本次学习报告。
- 实现知识点掌握状态计算。
- 实现核心素养表现摘要。
- 实现下一步学习建议。

验收：

- 报告包含薄弱知识点。
- 报告包含已补救知识点。
- 报告包含下一步建议。

## 9. 第八阶段：老师端最小版本

任务：

- 老师登录。已完成。
- 查看班级学生列表。已完成 MVP。
- 查看学生个人报告。已完成摘要版。
- 查看班级薄弱知识点。已完成。
- 查看题目表现。已完成题型和核心素养讲评。
- 按时间范围筛选班级报告。已完成 MVP。
- 按年级筛选班级报告。已完成 MVP。
- 导出班级报告。已完成 CSV MVP。
- 按知识点下钻学生名单。已完成 MVP。
- 按学生个人下钻错题清单。已完成 MVP。
- 导出学生错题清单。已完成 CSV MVP。
- 分配学生个人复盘任务。已完成 MVP。
- 学生查看老师分配的复盘任务。已完成 MVP。
- 学生完成复盘任务并获得成长奖励。已完成 MVP。
- 老师查看学生复盘完成反馈。已完成 MVP。
- 老师按复盘状态筛选学生。已完成 MVP。
- 学生填写复盘笔记。已完成 MVP，完成复盘时保存到补救路径记录。
- 学生从复盘任务进入同类题复测。已完成 MVP，仍只使用已发布题目。
- 老师温和提醒待复盘任务。已完成 MVP，记录提醒次数和最近提醒时间。
- 学生复盘笔记质量提示。已完成 MVP，引导学生写清错因、证据、条件和下次步骤。
- 同类题复测结果回写。已完成 MVP，学生从复盘任务进入同类题后，作答结果会回写到复盘任务。
- 学生端根据复测结果展示下一步行动。已完成 MVP，做对后进入变式题挑战，还需巩固时回到前置知识或基础同类题。
- 学生端下一步行动状态和奖励。已完成 MVP，变式题挑战或前置知识巩固完成后写入成长奖励，并在复盘任务中展示待完成/已完成。
- 学生端今日任务和成长轨迹。已完成 MVP，将复盘任务、下一步行动整理为今日任务/已完成任务，并从奖励事件生成累计成长轨迹。
- 学生端本周成长和核心素养成长摘要。已完成 MVP，按最近 7 天奖励事件和题目核心素养标签生成成长建议。
- 学生端按周成长回顾卡片。已完成 MVP，围绕复盘推进、前置补清和从难到会生成回顾卡片。
- 学生端核心素养目标选择。已完成 MVP，学生可选择一个 active 核心素养目标并在学习报告中回显。
- 学生端核心素养目标完成判定。已完成 MVP，目标选择后统计后续相关作答，达成后自动完成目标。
- 学生端核心素养目标奖励与历史。已完成 MVP，目标完成后写入 `literacy_progress` 奖励，并在学习报告中显示目标完成记录。
- 学生端核心素养目标多周期。已完成 MVP，支持周目标周期键、下周期重新开启、推荐下一目标和目标历史筛选。
- 学生端核心素养目标防刷。已完成 MVP，只统计目标开始后的已发布题目作答，过快或疑似猜测作答不计入完成证据，同一目标周期只发一次奖励。
- 学生端阶段性鼓励徽章。已完成 MVP，围绕复盘启动、本周成长、变式突破和诊断起步展示徽章状态。
- 老师批量提醒多名学生。已完成 MVP，支持按冷却时间跳过短时间内重复提醒。
- 老师按提醒记录筛选学生。已完成 MVP，支持已提醒、待提醒和提醒冷却中。
- 按复测结果生成班级汇总和个人建议。已完成 MVP，区分“已迁移成功”“继续巩固中”和“待复测”。
- 老师按复测结果筛选学生。已完成 MVP，支持已迁移成功、继续巩固中、待复测和暂无复测任务。
- 老师查看复盘趋势统计。已完成 MVP，统计最近 7 天分配、完成、提醒和复测数量。
- 老师查看分层复盘建议。已完成 MVP，按继续巩固、待复测、可挑战变式和需要分配复盘生成建议。
- 老师按分层复盘建议一键筛选学生。已完成 MVP，支持继续巩固中、待复测、可挑战变式和需要分配复盘。
- 老师导出复盘跟进名单。已完成 MVP，可按当前筛选口径导出待跟进学生、复测状态和个人建议。
- 老师基于复盘跟进名单批量分配下一轮任务。已完成 MVP，支持给已迁移成功学生分配变式挑战，给继续巩固学生分配前置知识巩固。
- 老师查看下一轮任务完成汇总。已完成 MVP，按变式题挑战和前置知识巩固统计待完成、已完成和完成率。
- 老师按下一轮任务类型筛选学生。已完成 MVP，支持筛选错题复盘、变式题挑战和前置知识巩固任务。
- 老师查看下一轮任务完成学生名单。已完成 MVP，可在班级报告看到变式题挑战和前置知识巩固的待完成/已完成学生。
- 老师为已完成的二次任务保存评价备注。已完成 MVP，支持已完成复盘、变式题挑战和前置知识巩固任务。
- 老师查看二次任务完成反馈和课堂讲评建议。已完成 MVP，按任务类型生成完成反馈和讲评建议，并进入老师端下钻与导出。
- 老师按备注状态筛选学生。已完成 MVP，支持筛选已有老师备注和待写老师备注的学生。
- 老师查看备注讲评清单。已完成 MVP，班级报告汇总最近老师备注、关联任务类型、知识点和课堂讲评建议。
- 老师导出备注讲评素材。已完成 MVP，班级报告 CSV 和复盘跟进 CSV 包含老师备注讲评清单、备注状态和待写备注数。
- 老师查看课堂讲评模板。已完成 MVP，按知识点或任务类型读取规则生成模板，不接 AI、不落库。
- 老师导出课堂讲评素材。已完成 MVP，支持 CSV 和 Markdown 导出；未发布或下架题目不导出题干/解析。
- 教师显式班级授权校验。已完成 MVP，教师访问具体班级报告、导出、学生下钻、复盘任务和讲评素材时必须有任教关系；`all/default` 全局口径仅管理员可用。
- 老师端跨班级工作台。已完成 MVP，`/api/teacher/classes` 返回当前老师授权班级，页面提供“我的班级”选择器，普通老师只能从授权班级进入报告；管理员保留全局口径。

验收：

- 老师只能查看授权班级。
- 老师能看到班级薄弱知识点排行。
- 老师能按年级和时间范围查看班级诊断口径。
- 老师能导出当前筛选口径下的班级报告。
- 老师能从薄弱知识点查看相关学生名单和讲评建议。
- 老师能从学生摘要查看个人错题清单和复盘建议。
- 老师能导出单个学生错题清单。
- 老师能把学生错题分配为个人复盘任务。
- 学生能看到老师分配的错题复盘任务。
- 学生完成复盘后能获得成长型奖励。
- 老师能看到复盘任务待完成和已完成状态。
- 老师能按待复盘、已复盘、暂无复盘任务筛选学生。
- 学生完成复盘时能写一句自己的复盘笔记。
- 学生能从复盘任务进入同知识点同类题复测，未发布题目不可见。
- 老师能对待完成复盘任务生成温和提醒记录。
- 学生填写复盘笔记时能看到方法性提示，不出现负面评价。
- 老师能看到学生复盘后的同类题复测结果，判断是否迁移成功。
- 学生完成同类题复测后，能看到清晰的下一步行动，而不是只看到对错结果。
- 学生能看到复测后下一步任务的待完成/已完成状态，完成变式挑战或前置巩固后获得成长型奖励。
- 学生能看到今日任务、已完成任务和累计成长轨迹，明确下一步行动和自己的成长来源。
- 学生能看到本周成长摘要和核心素养成长摘要，知道自己本周在哪些学习行为和化学能力上有积累。
- 学生能看到按周成长回顾卡片，知道本周复盘、补清和突破分别有哪些证据。
- 学生能选择一个核心素养目标，系统只保存当前登录学生自己的目标。
- 学生能为已完成目标重新开启下周期目标，并查看推荐目标和目标历史筛选。
- 系统能避免用目标开始前、未发布题目、过快或疑似猜测作答完成核心素养目标。
- 学生选择目标后，系统能根据后续相关作答自动完成目标，并记录核心素养进步奖励。
- 学生能查看核心素养目标完成历史，知道自己在哪个能力维度完成过阶段突破。
- 学生能看到阶段性鼓励徽章，徽章围绕成长行为而不是刷题数量。
- 老师登录后能直接看到自己的授权班级列表，不需要手动输入 `classId` 才能进入常规报告。
- 未绑定教师既不能在“我的班级”列表看到他人班级，也不能通过显式 `classId` 访问该班级。
- 老师能批量提醒多名有待复盘任务的学生。
- 系统能避免冷却期内重复提醒同一复盘任务。
- 老师能按提醒记录筛选学生，定位未提醒和冷却中的任务。
- 老师能在班级报告看到同类题复测迁移汇总，并在学生摘要中看到个人后续建议。
- 老师能按同类题复测结果筛选学生，快速定位已迁移成功和仍需巩固的学生。
- 老师能看到最近 7 天复盘推进趋势，并据此判断是先提醒、先复测还是先做分层讲评。
- 老师能看到分层复盘建议，快速决定不同学生群体的下一步任务。
- 老师能从分层复盘建议一键筛出对应学生群体，减少手工核对。
- 老师能导出当前筛选口径下的复盘跟进名单，用于课后批量跟进和备课。
- 老师能基于复盘跟进名单批量分配下一轮任务，且任务仍遵守已发布题目和学生端激励性表达边界。
- 老师能看到下一轮变式挑战和前置知识巩固的待完成、已完成与完成率，便于判断任务是否真正推进。
- 老师能按任务类型筛选学生，并导出当前任务类型下的复盘跟进名单。
- 老师能在下一轮任务汇总中看到待完成学生和已完成学生，并从名单进入个人下钻。
- 老师能为已完成任务保存评价备注，备注只在老师端展示，不进入学生端。
- 老师能看到按任务类型生成的二次任务完成反馈和课堂讲评建议，便于课堂讲评和后续跟进。
- 老师能按已有老师备注和待写老师备注筛选学生，快速找到可讲评素材和需要补写观察的完成任务。
- 老师能在班级报告和导出 CSV 中看到老师备注讲评清单，便于课堂讲评与课后跟进。
- 未绑定到某班级的教师访问该班级显式 `classId` 时会被拒绝。

## 10. 第九阶段：审核和题库管理

任务：

- 实现学校和班级维护。已完成 MVP，管理员可创建学校和班级。
- 实现教师任教关系。已完成 MVP，管理员可把教师绑定到班级，查看班级教师列表，并将班级内角色设为任课教师或班主任；后续教师端按显式班级授权访问。
- 实现学生班级归属。已完成 MVP，管理员可将学生加入班级，学生 `schoolId/classId` 写入用户记录。
- 实现管理端安全账号检索。已完成 MVP，管理员可按用户名、显示名或 ID 片段检索教师和学生，检索结果只返回授权运营字段，不返回密码哈希、会话凭证或模型密钥。
- 实现批量学生入班。已完成 MVP，管理员可粘贴多个学生用户名或 ID 批量加入班级；服务端跳过未找到和非学生账号，并对成功入班学生逐条写入组织审计。
- 实现学校级汇总。已完成 MVP，管理员可查看学校、班级、学生、教师、作答、正确率、补救任务和核心素养薄弱维度，并导出 CSV。
- 实现题库列表。
- 实现题库筛选。已完成 MVP，支持按审核状态、年级、题型和主知识点筛选。
- 实现题目编辑。已完成 MVP，支持题干、答案、解析、题型、难度、中位用时、主知识点和核心素养标签。
- 实现待审核状态。已完成。
- 实现一审通过即发布。已完成。
- 实现驳回。已完成。
- 实现审核记录。已完成。
- 实现题目批量维护。已完成 MVP，支持批量修改审核状态、难度、主知识点挂接和核心素养标签。
- 实现题库筛选条件保存。已完成 MVP，管理端本地保存上次筛选口径。
- 实现筛选方案命名保存。已完成 MVP，管理端可把个人方案、角色模板和共享方案保存到服务端。
- 实现筛选方案导出/导入。已完成 MVP，支持本地 JSON 导出和导入，导入后需保存到服务端才可用于批量预览。
- 实现批量操作预览。已完成 MVP，批量维护必须先生成服务端预览和 `previewToken`。
- 实现批量操作二次确认。已完成 MVP，提交时必须填写原因和确认文本。
- 实现批量操作审计。已完成 MVP，批量维护会生成 `AdminBatchOperation` 和逐题 `AuditRecord.batchId`。
- 实现管理端审计检索。已完成 MVP，支持按批次 ID、目标 ID 和动作筛选。

验收：

- 未审核题目不能进入学生端。
- 管理员能维护学校、班级、教师任教关系和学生班级归属。
- 管理员能通过安全账号目录检索教师和学生，减少手工复制用户 ID 的错误。
- 管理员能批量将学生加入班级，且非学生账号不会被错误加入。
- 管理员能查看和更新教师在班级内的 `teacher/head_teacher` 角色。
- 管理员能查看学校级汇总报表，普通教师不能访问该汇总。
- 学校组织维护写入审计记录。
- 审核修改有记录。
- 发布后学生端可用。
- 人工维护的知识点和核心素养标签优先于 AI 结果。
- 批量挂接知识点必须记录为人工来源，并逐题保留审核记录。
- 批量维护核心素养标签必须记录为人工来源，并逐题保留审核记录。
- 管理员能命名保存个人方案、角色模板和共享筛选方案。
- 管理员能导出和导入筛选方案 JSON，且不写入 API Key、学生记录或发布边界信息。
- 管理员批量维护前必须看到服务端操作预览，降低误操作风险。
- 管理员批量维护前必须完成原因填写和确认文本。
- 管理员能在批量完成后看到批量操作 ID，并跳转到审计检索。
- 批量维护不得把题目直接改为 `published`，不能绕过一审审核边界。

## 12. 推荐开发节奏

每次迭代只做一个小闭环：

1. 数据模型。
2. 后端接口。
3. 前端页面。
4. 测试。
5. 文档更新。

不要一次让 Codex “做完整系统”。每次给 Codex 的任务应具体到一个模块或一个流程。
