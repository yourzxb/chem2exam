# 项目路线图

## 阶段 1：MVP 学生诊断闭环

目标：验证“真题诊断 → 知识断点 → 补救路径 → 复测”的核心价值。

范围：

- 学生注册登录。
- 年级选择。
- 基础知识图谱。
- 真题式题库。
- 做题诊断。
- 错后追溯。
- 错后学习提示。
- 时间统计。
- 学生难度反馈。
- 基础奖励机制。
- 简单学习报告。

验收：

- 学生能完成一次完整诊断。
- 答错后能进入补救路径。
- 补救后能回到原知识点复测。
- 学生能看到鼓励性反馈和下一步建议。

## 阶段 2：老师端和题库管理

目标：让教师能使用系统进行班级诊断和题库维护。

范围：

- 老师登录。
- 班级诊断。
- 学生个人报告。
- 可编辑知识图谱。
- 题库管理。
- 人工录题。
- 批量导入题目。
- 核心素养评价字段。

验收：

- 老师能查看班级薄弱知识点。
- 老师能维护题目和知识点。
- 老师能看到学生核心素养表现。

## 阶段 3：整卷上传和 AI 审核流

目标：降低真题入库成本。

范围：

- 整卷上传。
- 答案和解析上传。
- AI 拆题。
- AI 答案解析对齐。
- AI 知识点挂接。
- AI 核心素养标签。
- 一审审核。
- 发布入库。

验收：

- AI 能将整卷拆为题目。
- AI 能推荐知识点和素养标签。
- 审核人能修改并发布。
- 学生端只能看到已发布题目。

## 阶段 4：AI 能力中心

目标：支持管理员接入国内大模型并按任务配置。

范围：

- DeepSeek、智谱 GLM 等 API 配置。
- API Key 加密存储。
- 任务级默认模型和备用模型。
- 后台 AI 任务队列。
- AI 调用日志。
- token 或费用统计。

验收：

- 管理员可新增模型配置。
- 管理员可测试连接。
- 不同 AI 任务可使用不同模型。
- 模型失败时可按规则重试或切备用模型。

## 阶段 5：精准调配和成长画像

目标：提升个性化推荐能力。

范围：

- 群体中位数动态更新。
- 个人掌握度模型。
- 题目动态难度校准。
- AI 精准调配。
- 核心素养成长画像。
- 老师分层教学建议。
- 多地区、多教材图谱版本。

验收：

- 系统能根据学生表现动态调整题目。
- 系统能识别从“难”到“会”的突破。
- 老师能获得可执行的分层教学建议。

## 开发顺序原则

优先级从高到低：

1. 真题诊断和知识断点定位。
2. 错后补救路径。
3. 人工审核和内容质量。
4. 老师端报告。
5. AI 自动化效率。
6. 精准调配和高级画像。

避免第一版堆太多 AI 功能，而忽略学生学习闭环。
