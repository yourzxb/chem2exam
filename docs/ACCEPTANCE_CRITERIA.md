# 验收清单

本文件用于开发完成后逐项检查，防止功能偏离需求。

## 1. 学生学习闭环

- [ ] 学生可以注册、登录、退出。
- [ ] 学生可以选择初三、高一、高二、高三。
- [ ] 学生可以查看对应年级知识图谱。
- [ ] 学生可以选择知识点开始做题。
- [ ] 系统记录每题开始时间和提交时间。
- [ ] 系统记录学生答案、正确与否和用时。
- [ ] 学生可以评价题目难度：容易、中等、难。
- [ ] 答错后系统显示错后学习导航。
- [ ] 错后学习导航包含错因、前置知识、学习路径、关键提示和鼓励语。
- [ ] 学生可以进入前置知识点补救。
- [ ] 补救完成后系统能回到原知识点复测。
- [ ] 系统能生成学生本次学习报告。

## 2. 学生端表达

- [ ] 学生端不出现“乱做”。
- [ ] 学生端不出现“低投入”。
- [ ] 学生端不出现“你不认真”。
- [ ] 过快答错时显示温和审题提醒。
- [ ] 认真思考但答错时显示前置知识补救建议。
- [ ] 答对反馈包含化学能力或核心素养相关鼓励。

## 3. 奖励机制

- [ ] 单题答对奖励低于补救完成奖励。
- [ ] 完成错题复盘可以获得奖励。
- [ ] 补清前置知识可以获得奖励。
- [ ] 从“难”到“会”可以获得高价值奖励。
- [ ] 奖励文案说明为什么奖励。
- [ ] 系统不鼓励反复刷简单题。

## 3.1 排行榜机制

- [ ] 排行榜基于成长行为，而不是单纯刷题数量。
- [ ] 至少支持本周榜。
- [ ] 学生能看到自己的排名。
- [ ] 学生端不显示负面排名文案。
- [ ] 重复刷同一简单题不会无限加分。
- [ ] 补救完成、错题复盘、从“难”到“会”能计入高价值榜单。

## 4. 题目和内容状态

- [ ] 每道题有审核状态。
- [ ] 每道题有发布状态。
- [ ] 学生端只展示已发布题目。
- [ ] 未审核题目不会进入学生端。
- [ ] 已驳回题目不会进入学生端。
- [ ] 每道正式题目至少挂接一个主知识点。
- [ ] 每道正式题目应有答案和解析。

## 5. 知识图谱

- [ ] 知识点支持年级归属。
- [ ] 知识点支持上下级关系。
- [ ] 知识点支持前置依赖关系。
- [ ] 答错后优先使用前置依赖推荐补救。
- [ ] 没有前置依赖时可以回退到上级知识点。
- [ ] 知识点状态能根据学生记录变化。

## 6. 时间统计

- [ ] 系统记录 durationSeconds。
- [ ] 系统使用中位数基准做时间评估。
- [ ] 系统能识别过快、较快、正常、较慢、卡顿。
- [ ] 时间评估不会直接在学生端变成负面标签。
- [ ] 老师端或内部可查看行为信号。

## 7. 核心素养评价

- [ ] 题目支持核心素养标签。
- [ ] 支持宏观辨识与微观探析。
- [ ] 支持变化观念与平衡思想。
- [ ] 支持证据推理与模型认知。
- [ ] 支持科学探究与创新意识。
- [ ] 支持科学态度与社会责任。
- [ ] 学生反馈能体现核心素养成长。
- [ ] 学生报告能按核心素养维度展示成长摘要和下一步行动。
- [ ] 学生能选择一个核心素养目标。
- [ ] 学生核心素养目标完成后能获得核心素养进步奖励。
- [ ] 学生能查看核心素养目标完成历史。
- [ ] 学生能看到按周成长回顾卡片和阶段性鼓励徽章。

## 8. AI 和审核

- [ ] AI 结果保存为候选结果。
- [ ] AI 结果进入人工审核流程。
- [ ] 一审通过后才能发布。
- [ ] 审核人可以修改 AI 结果。
- [ ] 人工审核结果优先于 AI 结果。
- [ ] 学生端无法访问未审核 AI 内容。
- [ ] AI 调用日志不记录 API Key 明文。

## 9. AI 模型配置

- [ ] 管理员可以新增模型配置。
- [ ] 管理员可以禁用模型配置。
- [ ] API Key 加密存储。
- [ ] 前端不显示 API Key 明文。
- [ ] 任务类型可以配置默认模型。
- [ ] 任务类型可以配置备用模型。
- [ ] 模型调用失败有错误记录。

## 10. 老师端

- [ ] 老师只能查看授权班级。
- [ ] 老师能查看班级薄弱知识点。
- [ ] 老师能查看学生个人报告。
- [ ] 老师能审核题目。
- [ ] 老师能发布审核通过题目。
- [ ] 老师能查看下一轮复盘任务的完成汇总。
- [ ] 老师能按任务类型筛选变式题挑战和前置知识巩固跟进名单。
- [ ] 老师能查看下一轮任务待完成和已完成学生名单。
- [ ] 老师能为已完成复盘或二次任务保存评价备注。
- [ ] 老师能看到按任务类型生成的二次任务完成反馈和课堂讲评建议。
- [ ] 老师能按老师备注状态筛选已有备注和待写备注学生。
- [ ] 老师能导出老师备注讲评清单，用于课堂讲评准备。

## 11. 数据安全

- [ ] 密码不明文存储。
- [ ] API Key 不进入前端。
- [ ] 学生数据按权限隔离。
- [ ] 老师不能查看未授权班级。
- [ ] 日志不记录敏感明文。

## 11.1 学校试点运营

- [ ] 管理员可按用户名、显示名或 ID 检索教师和学生。
- [ ] 管理员用户检索结果不返回密码哈希、会话凭证或模型密钥。
- [ ] 管理员可批量将学生加入班级。
- [ ] 批量入班会跳过非学生账号和未找到账号。
- [ ] 成功入班操作写入组织审计记录。
