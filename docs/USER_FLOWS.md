# 用户流程与页面规格

## 1. 学生学习主流程

```text
打开网站
→ 注册 / 登录
→ 选择年级
→ 查看知识图谱
→ 选择知识点
→ 开始诊断题
→ 提交答案
→ 查看反馈
→ 评价题目难度
→ 根据结果进入下一步
```

如果答对：

```text
显示解析
→ 显示核心素养鼓励
→ 记录用时和奖励
→ 进入下一题或完成节点
```

如果答错：

```text
显示错因提示
→ 显示前置知识点
→ 显示学习路径
→ 学生点击“先补前置知识”
→ 做前置题
→ 完成后回到原知识点复测
```

## 2. 登录 / 注册页

### 页面目标

让学生进入自己的学习档案。

### 主要元素

- 产品名称。
- 登录 / 注册切换。
- 用户名输入框。
- 密码输入框。
- 提交按钮。
- 错误提示。

### 规则

- 注册用户名不可重复。
- 密码正式系统必须哈希存储。
- 登录后进入学习首页。

## 3. 学习首页

### 页面目标

展示学生当前年级、奖励状态和学习入口。

### 主要元素

- 当前学生名称。
- 年级切换。
- 学习等级。
- 连续学习天数。
- 生命值。
- 宝石 / XP。
- 近期薄弱知识点。
- 进入知识图谱按钮。

### 规则

- 年级切换后，不同年级学习记录独立展示。
- 奖励信息不得鼓励刷简单题。

## 4. 知识图谱页

### 页面目标

让学生看到知识结构和自己的掌握状态。

### 主要元素

- 知识点节点。
- 节点关系线。
- 节点状态：未测试、待巩固、已掌握。
- 节点题量。
- 节点薄弱提示。
- 开始测试按钮。

### 规则

- 节点状态由学生答题记录和补救记录计算。
- 答错后的推荐路径优先使用 prerequisite 关系。
- 如果没有 prerequisite，再考虑 parent 关系。

## 5. 做题页

### 页面目标

完成诊断题并收集学习行为。

### 主要元素

- 当前知识点。
- 当前题号。
- 题干。
- 选项或答题区域。
- 提交按钮。
- 学习伙伴头像。
- 计时器内部运行，学生端可选择是否显示。

### 规则

- 题目展示时记录 startedAt。
- 提交时记录 submittedAt。
- 保存 durationSeconds。
- 提交后才能展示答案和解析。
- 正式系统中，学生端只能显示 published 题目。

## 6. 答题反馈面板

### 答对反馈

必须包含：

- 正确结果。
- 简短解析。
- 核心素养鼓励。
- 奖励说明。
- 难度反馈按钮。

示例：

```text
答对了。你能根据实验现象判断物质性质，说明证据推理能力正在提升。
```

### 答错反馈

必须包含：

- 正确答案。
- 关键解析。
- 错因提示。
- 推荐前置知识。
- 下一步路径。
- 鼓励语。
- 难度反馈按钮。

禁止只显示：

```text
答错了，正确答案是 B。
```

## 7. 错后学习导航

### 页面目标

告诉学生下一步怎么学。

### 主要元素

- “你可能卡在”诊断。
- 推荐前置知识点。
- 知识卡片入口。
- 前置巩固题入口。
- 回到原知识点复测说明。
- 鼓励语。

### 推荐文案结构

```text
这题暴露了一个小断点：{知识点或错因}

建议路径：
先复习「{前置知识点}」
→ 做 {n} 道基础题
→ 回到「{原知识点}」复测。

给你的提示：
{关键知识提醒}

鼓励：
{成长型鼓励}
```

## 8. 学习报告页

### 页面目标

让学生看到本次学习成果和下一步建议。

### 主要元素

- 做题数量。
- 正确率。
- 总用时。
- 薄弱知识点。
- 已补清前置知识。
- 核心素养表现。
- 奖励和徽章。
- 下一步建议。

### 规则

- 报告应强调成长和下一步行动。
- 不得直接显示负面人格评价。

## 9. 老师审核流程页面

后续阶段实现。

页面结构建议：

- 左侧：原试卷截图或原文。
- 中间：AI 拆出的题目结构。
- 右侧：知识点挂接、核心素养标签、置信度和理由。
- 底部：通过、修改后通过、驳回、重新 AI 分析。

### 规则

- 一审通过后发布。
- 修改需要留下审核记录。
- 未审核题目不得进入学生端。
