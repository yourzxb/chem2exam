## 6. 本轮前端实现记录

- 学生端改为“大题面优先”，新增沉浸做题全屏层，题目、选项、反馈和错后学习导航有更大展示面积。
- 老师端强化“我的班级”入口、筛选工作台、班级概况和复盘讲评模块，授权班级规则保持不变。
- 审核端新增队列概览、大题面审核栏、发布边界提示、低置信度核对建议和底部固定审核动作栏。
- 管理端把学校组织、班级授权、学生入班和学校汇总整合为“学校工作台”，并保留题库、知识图谱、AI 配置、筛选方案和审计导航。
- 首页保留四端入口和试点汇总，学校端能力放在管理端，不新增独立 `/school` 路由。
