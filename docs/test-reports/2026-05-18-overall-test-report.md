## 1. 测试范围

- 学校组织：管理员创建学校和班级，绑定教师与学生，维护任课教师和班主任角色。
- 账号目录：管理员按用户名、显示名或 ID 检索教师和学生，结果只返回授权运营所需字段。
- 批量入班：管理员批量添加学生到班级，非学生账号和未找到标识会被跳过，成功入班写入组织审计。
- 教师工作台：老师端读取“我的班级”，选择授权班级后复用报告、下钻、导出、复盘任务和课堂讲评素材。
- 学校级汇总：管理员查看学校级班级数、学生数、教师数、作答量、正确率、补救任务和核心素养薄弱维度，并导出 CSV。
- 权限边界：普通教师只能访问自己被授权的班级，未绑定教师访问显式班级返回 403。
- 学生端红线：学生端仍只读取已发布题目，仍不展示负面标签。
- 审核红线：未发布题仍不可进入学生端，AI 输出和批量维护不能绕过人工一审发布边界。
- 浏览器抽查：覆盖 `/admin`、`/teacher`、`/student`、`/review` 四个核心页面。
